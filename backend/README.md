FRIEND SYSTEM BACKEND 

This is a simple built backend with Node.js, express and MySQL.
This allows users to send, accept, deny, and view friend requests.

----------

INSTALLATION

After cloning the repository: 
cd into backend 
should look like C:\Users\xxxxx\Lab3\backend
then install dependencies with npm install.
to start running the server do npm start / or node server.js


axios was used for testing but will keep it in for now.

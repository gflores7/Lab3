1. Problem Statement 
What problem does this solve? 

Users currently cannot update their personal preferences or account display information after registration. This limits personalization and reduces user control over their account. 

The Settings Page solves this by providing a centralized interface where users can view and update their account preferences. 

2. User Flow 
Step by step from start to finish 

1.User logs into the application 
2.User clicks “Settings” in the navigation bar 
3.Settings page loads with current user data 
4.User edits one or more fields: 
    *Display Name 
    *Bio 
    *Privacy Setting (Public / Private) 
    *Email Notifications (On / Off) 
5.User clicks “Save Changes” 
6.Backend validates input 
7.Database updates the user record 
8.Success message appears 
9.Page refresh shows persisted updates
